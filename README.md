# مختبر التفكير النقدي بالذكاء الاصطناعي
### AI Critical Thinking Lab

نظام تعليمي مبتكر يسخّر الذكاء الاصطناعي كـ **شريك فكري سقراطي** يتحدى افتراضات المتعلم ويعزز مهارات التفكير النقدي والإبداع وعمق الاستدلال المنطقي، بدلاً من تقديم إجابات جاهزة وسطحية.

---

## 🌟 أبرز مميزات المشروع

- **الشريك الفكري السقراطي:** محرك حوار ذكي مبني على نماذج OpenAI لا يقدم حلولاً جاهزة، بل يطرح أسئلة استقصائية ذكية وموجهة تكشف الانحيازات وتطالب بالأدلة.
- **منهجية التعلم الرباعية:**
  1. **التحدي (Challenge):** استعراض معضلات واقعية مفتوحة ومثيرة للتفكير.
  2. **الحوار السقراطي (Socratic Dialogue):** نقاش تفاعلي متعدد الجولات مع الذكاء الاصطناعي.
  3. **التأمل الذاتي (Reflection):** كتابة تحليل واستنتاج مبرر مع مؤشر فوري لعمق التفكير.
  4. **التقييم الشامل (Evaluation):** تقييم راداري تفاعلي لأربع مهارات إدراكية (التفكير النقدي، الإبداع، جودة الأدلة، عمق التحليل).
- **لوحة تحكم متقدمة للمعلم:** متابعة أداء الطلاب، إحصائيات الجلسات، وإمكانية إضافة معضلات وتحديات مخصصة.
- **قسم تعريفي ودليل استخدام متكامل:** يشرح الفئات المستهدفة، دليل الاستخدام، تقنيات الذكاء الاصطناعي المستخدمة، والأثر التعليمي على المعلم والمتعلم.
- **دعم ثنائي اللغة كامل:** واجهة متجاوبة تدعم اللغتين العربية (RTL) والإنجليزية (LTR).
- **بنية تخزين هجينة ومرنة:** إمكانية التشغيل الساكن عبر التخزين المحلي للمتصفح (IndexedDB / Dexie.js)، أو التشغيل الخادومي الآمن عبر ASP.NET مع حفظ ملفات JSON.

---

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** HTML5, Modern CSS3 (Cosmic Glassmorphism Theme), Vanilla JavaScript (ES6+ Modules).
- **التمثيل البياني (Visualization):** [Chart.js](https://www.chartjs.org/) لمخططات الرادار وتتبع المهارات.
- **التخزين المحلي (Client Storage):** [Dexie.js](https://dexie.org/) / IndexedDB.
- **محرك الذكاء الاصطناعي (AI Engine):** OpenAI Chat Completions API (`gpt-4o-mini`, `gpt-4o`, `gpt-5.2`) مع نمط الاستجابة المهيكلة (Strict JSON Mode).
- **الواجهة الخلفية (Backend - اختياري):** 
  - مسار ASP.NET 4.8 عبر `api.ashx`.
  - مسار ASP.NET Core عبر `Program.cs`.

---

## 🚀 طريقة التشغيل والنشر

### 1. التشغيل المحلي الساكن (Static / Local)
يمكنك فتح `index.html` مباشرة في أي متصفح حديث، أو تشغيل خادم محلي:
```bash
# باستخدام Python
python -m http.server 8080

# باستخدام Node.js
npx serve .
```

### 2. النشر على استضافة ASP.NET (مثل SmarterASP.NET)
- ارفع ملفات الموقع مع `api.ashx` و `web.config`.
- تأكد من ضبط الـ App Pool على ASP.NET 4.8 / Integrated.
- سيقوم الخادم بإنشاء مجلد `App_Data` لحفظ بيانات المستخدمين والتحديات في ملفات JSON.
